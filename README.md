# Electronic-Projects-Tool
This program aims to assist electrical engineers in the execution of project budgets, without the need to prepare documentation.

## Tools used: 

- **Sqlite library(the values are stored in a database)**
- **tkinter library**
- **docx library**

## Program funcinalities:

- **Cadastro do cliente: Where it registers the customer and is stored in a database to be included in the final budget;**
- **Serviços a orçar: The first quote you need to know exactly how big the place is;**
- **Comercial: If the client wants to add something else to their project and business parameters;**
- **Resumo/Orçamento:Where the finalized budget appears, and you have the option to download a word of the complete budget;**
